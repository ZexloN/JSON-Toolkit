# 🧩 JSON Toolkit

A lightweight browser-based JSON utility for formatting, validating, minifying and inspecting JSON data.

Built with pure HTML, CSS and JavaScript — no frameworks or external dependencies.

## ✨ Features

- 🎨 JSON formatting
- 📦 JSON minification
- ✅ JSON validation
- 📋 Copy formatted/minified JSON
- 📊 JSON statistics
- 🔍 JSON type detection
- 🔢 Key counter
- 💾 JSON size calculation
- 🧪 Built-in example data
- 🌙 Dark developer-focused interface
- ⚡ Runs entirely in the browser

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM API

No frameworks or external libraries are required.
